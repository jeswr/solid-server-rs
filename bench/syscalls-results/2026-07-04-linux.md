## Caveats

- strace slows the traced server heavily; reactor-amortized syscalls (epoll_wait, timer maintenance) can BATCH differently under trace — per-request I/O syscalls (read/recvfrom/write/sendto/writev) are robust, amortized ones are approximate.
- idle_baseline shows the background syscall rate the counts sit on; at the configured N its contribution per request is negligible but nonzero.
- t3-class EC2 exposes no hardware PMU: perf uses software counters/cpu-clock sampling.
